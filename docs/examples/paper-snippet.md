# Paper/Preprint Licensing Example

This example shows how to license academic papers under PIRW-ACL (§14).

## BibTeX Citation

```bibtex
@preprint{smith_novel_approach_2026,
  title = {A Novel Approach to Climate Data Analysis},
  author = {Smith, Jane and Doe, John},
  year = {2026},
  month = May,
  url = {https://example-preprint-server.org/papers/2026.05.001},
  archiveprefix = {arXiv},
  eprint = {2605.xxxxx},
  license = {PIRW-ACL v1.0 (NC-Default + BY)},
  note = {SPDX-License-Identifier: LicenseRef-PIRW-ACL-1.0}
}
```

## License Notice for Paper

```
This preprint is licensed under PIRW-ACL v1.0 (NC-Default + BY).
Full license: https://github.com/<YOUR-ORG>/pirw-license/blob/main/LICENSE
SPDX-License-Identifier: LicenseRef-PIRW-ACL-1.0
```

## Markdown README Format

```markdown
# A Novel Approach to Climate Data Analysis

**License:** PIRW-ACL v1.0 (NC-Default + BY)  
**SPDX-License-Identifier:** `LicenseRef-PIRW-ACL-1.0`  
**Authors:** Dr. Jane Smith, Prof. John Doe  
**Date:** 2026-05-24  

## Citation

Smith, J., & Doe, J. (2026). A novel approach to climate data analysis. 
*ArXiv Preprint* arXiv:2605.xxxxx. Licensed under PIRW-ACL v1.0.
```
