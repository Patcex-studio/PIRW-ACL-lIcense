# Integration Examples

Copy-paste ready templates for licensing your work under PIRW-ACL v1.0 (§14).

## By Work Type

### 📊 [Datasets & Data](dataset-snippet.md)
Complete examples for research datasets, data files, repositories.

**Includes:** README headers, JSON-LD metadata, BibTeX citations, CSV headers, portal templates.

---

### 📄 [Papers & Preprints](paper-snippet.md)
Complete examples for academic papers, preprints, theses.

**Includes:** BibTeX entries, license notices, metadata templates, citation formats.

---

### 💻 [Code & Software](code-snippet.md)
Complete examples for repositories, libraries, tools, frameworks.

**Includes:** SPDX headers, package.json, README templates, BibTeX citations, reuse.toml, CI/CD.

---

## Quick Start

1. **Choose your work type** above
2. **Copy relevant snippet**
3. **Replace placeholders:** <YOUR-ORG>, names, dates, URLs
4. **Add to your project**

## Key Elements (All Examples)

✅ **SPDX Identifier:** `LicenseRef-PIRW-ACL-1.0`  
✅ **License Tier:** Explicitly stated (NC-Default/Commercial-Allowed, BY/SA)  
✅ **Attribution Chain:** Creator, affiliation, date, source URL  
✅ **Copy-Paste Ready:** Replace placeholders, use immediately
